# VKML Compiler Scripts

This directory contains utility scripts for the VKML compiler.

## SPIR-V Validation Scripts

Two scripts are provided for validating SPIR-V binaries generated by the compiler:

### validate_spirv.py (Recommended)

Python script for cross-platform SPIR-V validation.

**Usage:**
```bash
# Basic validation
./scripts/validate_spirv.py shader.spv

# Validate for specific Vulkan version
./scripts/validate_spirv.py -t vulkan1.2 shader.spv

# Verbose output
./scripts/validate_spirv.py -v shader.spv

# Install spirv-tools and validate
./scripts/validate_spirv.py -i shader.spv
```

**Options:**
- `-h, --help`: Show help message
- `-v, --verbose`: Enable verbose output
- `-t, --target-env ENV`: Target environment (vulkan1.0, vulkan1.2, etc.)
- `-i, --install`: Attempt to install spirv-tools

### validate_spirv.sh

Bash script for Unix-like systems.

**Usage:**
```bash
# Basic validation
./scripts/validate_spirv.sh shader.spv

# Validate for specific Vulkan version
./scripts/validate_spirv.sh -t vulkan1.2 shader.spv

# Verbose output
./scripts/validate_spirv.sh -v shader.spv

# Install spirv-tools and validate
./scripts/validate_spirv.sh -i shader.spv
```

**Options:**
- `-h, --help`: Show help message
- `-v, --verbose`: Enable verbose output
- `-t, --target-env ENV`: Target environment
- `-i, --install`: Attempt to install spirv-tools

## Requirements

Both scripts require **spirv-val** from the SPIR-V Tools package:

- **Ubuntu/Debian**: `sudo apt-get install spirv-tools`
- **Fedora/RHEL**: `sudo yum install spirv-tools`
- **macOS**: `brew install spirv-tools`
- **Manual**: [SPIRV-Tools GitHub](https://github.com/KhronosGroup/SPIRV-Tools)

The `-i` flag can attempt automatic installation on supported systems.

## Target Environments

Supported target environments:

### Vulkan Targets
- `vulkan1.0` - Vulkan 1.0 / SPIR-V 1.0
- `vulkan1.1` - Vulkan 1.1 / SPIR-V 1.3
- `vulkan1.2` - Vulkan 1.2 / SPIR-V 1.5
- `vulkan1.3` - Vulkan 1.3 / SPIR-V 1.6

### SPIR-V Targets
- `spv1.0` through `spv1.6` - Specific SPIR-V versions

## Integration with C++ Code

Use the `VulkanPipeline::saveSPIRVToFile()` method to save SPIR-V binaries:

```cpp
#include "VulkanPipeline.h"

// Create pipeline
auto compiler = vkml::Compiler::getInstance();
auto vulkanPipeline = compiler->createVulkanPipeline();

// Save SPIR-V to file
if (vulkanPipeline->saveSPIRVToFile("shader.spv")) {
    std::cout << "SPIR-V saved successfully\n";
}

// Validate using system command
std::system("scripts/validate_spirv.py shader.spv");
```

## Troubleshooting

### spirv-val not found
Install SPIR-V Tools using your package manager or use the `-i` flag.

### Permission denied
Make scripts executable:
```bash
chmod +x scripts/validate_spirv.py
chmod +x scripts/validate_spirv.sh
```

### Validation errors
Check that:
1. Target environment matches compilation settings
2. SPIR-V binary is not corrupted
3. spirv-tools version is compatible with target SPIR-V version
